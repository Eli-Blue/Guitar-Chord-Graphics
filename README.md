# Guitar-Chord-Graphics

Create your own guitar chord posters.

## Poster Creator Website

This repository includes a simple static website for building printable guitar chord posters.

### Run locally

Open `index.html` from the repository root directly in a browser, or serve the folder with a static file server.

### Usage

1. Enter a poster title and optional subtitle.
2. Add chords one per line in this format: `Name Position`
   - Example: `C x32010`
   - Position must be 6 characters (`x`, `0`-`9`) from low E to high e.
   - Fretted notes must fit within a 5-fret span.
3. Click **Generate Poster** to refresh the preview.
4. Click **Print / Save PDF** to print or export your poster.
